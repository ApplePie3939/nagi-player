# 凪プレイヤー

ブラウザで音声・動画を再生できる、シンプルなオフライン対応プレイヤーです。

[凪プレイヤーを開く](https://applepie3939.github.io/nagi-player/)

## できること

- 同梱のテスト用音声・動画を再生する
- この端末にある音声・動画を追加して再生する
- 再生、一時停止、前後の項目への移動、再生位置の変更を行う
- 対応する動画で全画面表示とピクチャ・イン・ピクチャを使う
- 対応ブラウザのロック画面や通知から再生を操作する
- 一度開いた後は、通信がない場所でも同梱メディアを再生する

## 使い方

1. [公開版](https://applepie3939.github.io/nagi-player/)を開きます。
2. 同梱メディアは、再生リストから選んで「再生」を押します。
3. 自分のファイルを再生する場合は「ファイルを選ぶ」から音声または動画を選びます。
4. 再生リストの「編集」では、追加したファイルをリストから外したり、同梱メディアと追加したファイルを非表示にしたりできます。

リストから外しても、端末にある元ファイルは削除されません。非表示にした素材は、「編集」中の「非表示の素材」から戻せます。追加したファイルの非表示状態は、ページを閉じるか更新するまで保持されます。

## 端末のファイルについて

MP3、M4A、AAC、WAV、FLAC、MP4、M4V、MOV、WebM形式を選べます。1ファイルは5 GBまで、合計20件まで追加できます。

選んだファイルはサーバーへアップロードされません。このブラウザの現在の画面内でだけ扱われ、ページを閉じると再生リストからも消えます。

## iPhone / iPadでアプリのように使う

Safariで公開版を開き、共有ボタンから「ホーム画面に追加」を選びます。追加後はホーム画面のアイコンから起動できます。

初回にオンラインで開いた後は、同梱メディアとアプリ画面が端末に保存されるため、オフラインでも再生できます。更新を受け取るには、通信できる状態で一度ページを開き直してください。

## ご注意

- 全画面表示、ピクチャ・イン・ピクチャ、ロック画面操作、バックグラウンド再生は、ブラウザとOSの対応状況によって利用できない場合があります。
- ローカルファイルの再生可否は、ファイル形式だけでなく端末・ブラウザが対応するコーデックにも依存します。
- 同梱メディアはテスト用です。素材のライセンス情報は [assets/media/README.md](assets/media/README.md) を確認してください。

## 開発者向け

開発・公開手順や同梱素材の差し替え方法は、プロジェクト内の設定と各素材フォルダのREADMEを参照してください。公開前には、追加するすべての素材について配布許諾を確認してください。
