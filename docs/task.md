# Expo iPhone バックグラウンド・メディアプレイヤー 実装タスク

## 1. 目的と前提

利用許諾済みの短尺 MP3 / MP4 をアプリ内で再生できる、日本語 UI の iPhone 向けメディアプレイヤーを実装する。MP3 は画面ロック中・バックグラウンド中も継続再生し、MP4 はアプリを離れたとき Picture in Picture（PiP）へ遷移できるようにする。

- 対象は iPhone 実機であり、Expo Go ではなく development build で検証する。
- Expo Router を使用しない、単一画面の TypeScript Expo アプリとする。
- 初期化時は、その時点の安定版 Expo TypeScript テンプレートを使用する。

### 対象範囲

- アプリ同梱の固定プレイリストにある MP3 / MP4 の再生
- 再生・一時停止、前後スキップ、シーク、再生時間の表示
- MP3 のバックグラウンド再生とロック画面／コントロールセンター操作
- MP4 のインライン再生、手動 PiP、自動 PiP
- EAS development build での iPhone 実機検証

### 対象外

- ファイルアプリからのメディア選択
- URL ストリーミング
- 再生リストの編集
- 再生履歴・お気に入り・アカウント機能

## 2. 機能要件

### 再生リストと画面

- 固定の再生リストを表示し、ユーザーが再生対象を選択できること。
- 選択中メディアのタイトル、種別（音声／動画）、アーティスト名、アートワークを表示すること。
- 再生／一時停止、前へ、次へ、シークバー、経過時間、総時間を表示・操作できること。
- 再生終了時は次の項目があれば自動再生し、末尾項目では停止すること。

### MP3 再生

- `expo-audio` を使用して再生すること。
- 端末のロック中およびアプリのバックグラウンド化後も再生を継続すること。
- ロック画面とコントロールセンターに、タイトル、アーティスト、アートワーク、再生操作を公開すること。
- 選曲またはメディア種別切替時は、既存プレイヤーを停止・解放して二重再生を防ぐこと。

### MP4 再生

- `expo-video` を使用し、画面内で再生できること。
- 手動で PiP を開始するボタンを表示すること。
- アプリがバックグラウンドへ移ったとき、自動 PiP を有効にすること。
- PiP 終了後にアプリへ戻っても、再生状態と再生位置の表示に不整合がないこと。

### iOS ネイティブ設定

- `app.json` の config plugin で `expo-audio` のバックグラウンド再生を有効化すること。
- `expo-video` のバックグラウンド再生および PiP を有効化すること。
- iOS の `UIBackgroundModes` に `audio` を設定し、ネイティブビルドへ反映すること。

## 3. アセットとメタデータ

正式素材は後でユーザーが提供する。実装時は次の構成を用意し、素材を差し替えても UI・再生制御の変更が最小限になるようにする。

- `assets/media/` に MP3 と MP4 を配置する。
- `assets/artwork/` に各項目のアートワーク画像を配置する。
- アセットの import／登録と、再生リストのメタデータ定義を分離する。
- 各再生リスト項目には少なくとも ID、タイトル、アーティスト、種別、メディアアセット、アートワークを持たせる。
- 提供素材は、アプリへの同梱および配布に必要な利用許諾を満たしていることを確認する。
