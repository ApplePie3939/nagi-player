# Expo iPhone バックグラウンド・メディアプレイヤー

## 概要

Expo の新規 TypeScript アプリとして、同梱した利用許諾済みの短尺 MP3/MP4 を再生できる日本語 UI のプレイヤーを作る。MP3 はロック中・バックグラウンドでも継続再生し、MP4 はアプリを離れると自動で PiP へ遷移する。実機用 development build で検証する。

## 実装変更

- Expo Router を使わない単一画面アプリとして初期化し、MP3 と MP4 を持つ固定の再生リストを定義する。
- 選択中メディアのタイトル、種別、再生/一時停止、前後スキップ、シークバー、経過時間・総時間を表示する。
- MP3 は `expo-audio`、MP4 は `expo-video` で再生し、選曲時には前のプレイヤーを停止・解放して二重再生を防ぐ。
- MP3 はロック画面／コントロールセンターにタイトル・アーティスト・アートワークと再生操作を公開する。
- MP4 はインライン表示、手動 PiP ボタン、およびアプリをバックグラウンドへ移した際の自動 PiP を有効化する。
- `app.json` の config plugin で `expo-audio` の背景再生、`expo-video` の背景再生・PiP を有効化し、iOS の `UIBackgroundModes: ["audio"]` をネイティブビルドへ反映する。
- 利用許諾済みの短尺 MP3/MP4 とアートワークを `assets` に同梱し、アセット登録と再生リストのメタデータを分離して、後から素材を差し替えやすくする。
- EAS development build の設定と、iPhone 実機へ入れて起動する手順を README に記載する。

## テスト計画

- TypeScript・静的チェックを通し、再生リスト選択、再生/一時停止、シーク、前後スキップ、終了後の次項目遷移を確認する。
- iPhone 実機で MP3 の消音モード、画面ロック、アプリのバックグラウンド化、ロック画面操作を確認する。
- iPhone 実機で MP4 の再生、手動 PiP、自動 PiP、PiP 終了後のアプリ復帰を確認する。
- MP3 と MP4 を連続して切り替え、同時再生・停止漏れ・再生位置表示の不整合がないことを確認する。

## 前提

- 初版の再生対象はアプリ同梱メディアのみで、ファイルアプリ選択・URL ストリーミング・ライブラリ編集・再生履歴は対象外。
- 対象は iPhone 実機。Expo Go ではなく、ネイティブ設定を含む development build で検証する。
- 再生終了時は、再生リストに次の項目があれば自動で再生し、末尾では停止する。
